این پوشه دو برنامهٔ جدا دارد:

- `api/`: API تحریریه برای Railway. تنها این برنامه به Neon متصل می‌شود.
- `web/`: پنل فارسی برای پروژهٔ جداگانهٔ Vercel.

مدل داده و محتوای اولیه در `db/0001_schema.sql` و `db/0002_seed.sql` قرار دارند. موجودی دقیق سایت در `docs/inventory.md` است. پروژهٔ Neon مستقل `nahanja-content` با شناسهٔ `lucky-wave-16672147`، دیتابیس `nahanja_content` و شاخهٔ `staging` با شناسهٔ `br-quiet-feather-b1wlx1wk` ساخته و روی هر دو شاخه seed اجرا شده است. API در `https://cms-api-production-530b.up.railway.app` و پنل در `https://nahanja-admin.vercel.app` منتشر شده‌اند. هر دو از پوشه‌های مستقل همین مخزن و شاخهٔ `feat/nahanja-admin-cms` ساخته می‌شوند؛ سایت عمومی همچنان از `main` منتشر می‌شود.

## راه‌اندازی

1. Google Web Client ID موجود روی API و پنل ثبت شده و `https://nahanja-admin.vercel.app` به Authorized JavaScript origins افزوده شده است. نخستین مدیر `amirhfz95@gmail.com` در Neon به‌صورت pending ثبت شده و تنها پس از ورود با حساب تأییدشده فعال می‌شود.
2. Blob store عمومی `nahanja-admin-blob` ساخته و کلید خواندن/نوشتن آن فقط در متغیر محرمانهٔ `cms-api` در Railway ثبت شده است. کلید Blob و Neon در مرورگر یا build پنل نیستند.
3. `DATABASE_URL` pooled، `GOOGLE_CLIENT_ID`، `ADMIN_ORIGIN` و `CMS_PUBLIC_URL` روی API تنظیم شده‌اند. Railway از پوشهٔ `api/` با `npm start` و healthcheck `/health` استقرار موفق دارد.
4. پنل Vite از پوشهٔ `web/` به‌صورت پروژهٔ مستقل Vercel آماده است. دکمهٔ واقعی ورود Google در دامنهٔ پنل نمایش داده می‌شود؛ انتخاب حساب و اولین ورود مدیر هنوز باید به‌صورت انتهابه‌انتها تأیید شود.
5. adapter سایت در `public/nahanja-cms.js` به خروجی عمومی CMS از مسیر هم‌مبدا `/cms-content` متصل است و هنگام قطعی CMS به محتوای ثابت ممیزی‌شده برمی‌گردد. این تغییر فعلاً در Draft PR است و تا ادغام با `main` روی سایت عمومی فعال نمی‌شود. پیش از ادغام، preview شاخه و انتشار یک کتاب/جلد آزمایشی باید بررسی شوند.

## امکانات موجود در کد

API: فهرست و جست‌وجوی محتوا، ایجاد و ویرایش نسخه‌دار، حذف نرم و بازیابی، انتشار و لغو انتشار اتمیک release، خروجی عمومی فقط از release فعال، کتابخانه و آپلود مستقیم Vercel Blob، ویرایش alt/caption، رویدادهای audit، کنترل نقش و تأیید Google ID token. درخواست بدون ورود به مسیر مدیریت پاسخ 401 می‌گیرد.

پنل: گروه‌بندی انواع محتوا، فیلتر وضعیت، جست‌وجو و صفحه‌بندی، فرم فارسی برای فیلدهای معمول متن و عدد و آرایه، ویرایش پیشرفتهٔ JSON برای داده‌های پیچیده، ترتیب نمایش، روشن/خاموش‌کردن و جابه‌جایی بخش‌های Home، تنظیم روابط، انتخاب فایل برای جلد/تصویر/صوت/ویدئو، بارگذاری فایل، پیش‌نمایش draft، انتشار، لغو انتشار و زباله‌دان. پیش‌نمایش فعلی یک کارت محتوایی در پنل است؛ برای دیدن **همان صفحهٔ عمومی** با draft، نشست preview کوتاه‌مدت هنوز لازم است.

دادهٔ کامل محتوا در JSON محفوظ می‌ماند و فرم عمومی فیلدهای ساده را ویرایش می‌کند. فرم‌های اختصاصی هر نوع، کامل‌کردن `ui_copy` و متن همهٔ صفحه‌ها، ابزار مدیریت نقش‌ها و workflow بررسی آثار اعضا مرحلهٔ بعد هستند. افزوده‌شدن `podcast` و `video` به مدل، به‌معنای وجود فایل صوتی/ویدئویی واقعی در سایت اولیه نیست.

## API

| مسیر | دسترسی | کاربرد |
|---|---|---|
| `GET /v1/public/release` | عمومی | فقط نسخهٔ منتشرشده، همراه روابط و مدیا |
| `GET /v1/admin/me`, `/types`, `/items`, `/items/:id` | مدیر | هویت، نوع‌ها، فهرست و جزئیات draft/published |
| `POST /v1/admin/items`, `PUT /v1/admin/items/:id` | owner/editor | ایجاد و ویرایش نسخه‌دار با کنترل نسخهٔ همزمان |
| `DELETE /v1/admin/items/:id`, `POST .../restore` | owner/editor | زباله‌دان و بازیابی |
| `POST .../publish`, `POST .../unpublish` | owner/publisher | ساخت release جدید و تعویض اتمیک |
| `POST /v1/admin/upload`, `GET /v1/admin/media`, `PUT /v1/admin/media/:id` | owner/editor برای نوشتن | آپلود، فهرست و شرح مدیا |

برای اجرا در سیستم محلی: `npm install` در هر دو پوشه، سپس `npm start` در `api/` و `npm run dev` در `web/`. متغیرها را بر اساس فایل‌های نمونه تنظیم کنید. رمزها در این مخزن یا سند ذخیره نشده‌اند.

- Build رابط Vite و syntax check API موفق.
- DDL و seed روی Neon staging و شاخهٔ اصلی: ۴۶ محتوا، ۱۰۵ رابطه، ۳۹ محتوای منتشرشده، ۳ کتاب.
- آزمون محلی PostgreSQL سازگار: ایجاد، ویرایش با کنترل نسخه، انتشار، لغو انتشار، حذف و بازیابی موفق.
- API محلی با Neon staging: `/health` سالم، `/v1/public/release` دارای ۳۹ مورد/۳ کتاب، `/v1/admin/items` بدون هویت پاسخ 401.
- استقرار پنل و API، صفحهٔ ورود Google و ثبت متغیر Blob بررسی شدند. انتخاب حساب Google و آپلود واقعی رسانه هنوز تأیید انتهابه‌انتها ندارند.
- syntax و نگاشت adapter سایت با دادهٔ نمونه و build پنل پس از افزودن فرم‌های فارسی موفق بود. preview شاخه Home، کتاب‌ها، عکس‌ها و پادکست‌ها را از release موجود بدون خطای مرورگر نمایش داد. یک ویرایش واقعی از پنل تا سایت هنوز باید آزموده شود.
